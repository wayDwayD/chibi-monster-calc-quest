# ちびモンスター けいさんクエスト

4〜6歳向けの計算ゲーム。モンスターを育てて(90秒)ボスを倒す、ローグライク風。
ブラウザだけで動く単体のHTML(素材を埋め込み済み)です。

## 遊び方
`index.html` をブラウザで開く。iPad/iPhone は横向き推奨。GitHub Pages に置けばURLで遊べます。

## 主な仕様
- 子ども3人分のプロフィール(ガチャ・ずかん・コイン・進行が別々)。記録はブラウザの localStorage に保存。(以前の2人ぶんの記録もそのまま読めます)
- むずかしさ: ようちえん / しょうがく1ねんせい
- 育成90秒(レベルアップ → Lv3で とくぎが めざめる → Lv5で しんか) → ボス戦65秒。レベル26段階(通常13+裏13)、**各レベルは3ステージ**(L-1 ミニボス=HP60%・ひとつ やさしい むずかしさから / L-2 さいせん=別のボスHP80% / L-3 レベルボス=HP100%)。L-3 をクリアすると次のレベルが開きます。同じ むずかしさを3回くりかえして「かんがえずに とける」自信をつける(公文式のくりかえし)ねらいです。育成中に武器・防具を選ぶ場面はありません(子どもには難しいため廃止。もっていた武器・防具はずかんに残ります)
- ドリルでコイン、ガチャ(ハズレなし)で仲間・おまもり・ステッカー
- なかまは **76体**(はじめの16体 + `src/monsters_extra.json` の60体)。それぞれに **レア度**(★ふつう/★★レア/★★★スーパーレア/★★★★ウルトラレア)、**属性**(8種)、**とくぎ**(じかんのびーる/まもりのひかり/ひらめき/ひっさつ/おたから/れんぞくパワー)があり、よわいモンスターでも とくぎで役に立ちます
- **★の評価**: ★=クリア / ★★=さいしょの こたえの せいかいりつ80%以上 / ★★★=90%以上 かつ こたえる速さ(中央値)7秒以内(小学生モードは6秒)。★が増えるたびに コイン(★★で+2、★★★で+3、ステージごとに1回)。むかしの記録でクリア済みのレベルは3ステージとも クリア扱い。ミニボス26体は `SB`(`src/game.src.html`)・ずかんの「ミニボス」タブに載ります
- ボスにはそれぞれ**じゃくてん属性**があり、同じ属性のなかまで たたかうと ダメージ2倍(「こうかばつぐん!」)。ステージ選択でじゃくてん(絵文字)が見え、それに合うなかまには ◎ が付きます。とくぎは Lv3 で めざめます
- ガチャ(12%でなかま、20回出なければ必ず1体)は、レア度の重み 60/28/10/2 で選びます。スーパーレアは5体、ウルトラレアは10体 集めてから出ます。ダブりは かけらになり、10こで すきななかまを よべます。ボスを倒しても なかまは増えません(ガチャだけ)
- ザコ敵は **25種類**(必要な攻撃回数は1〜3回でばらばら)。レア敵の **コインおばけ** が時々出ます: ぎん(+4コイン・約5%)/きん(+12コイン・約1.5%)/にじ(+40コイン・約0.3%)。最初の2体には出ず、1回の育成で最大2体。倒すとコインが降ります(1回の育成の平均は +1.5〜4コイン)。ずかんの「てき」にも載ります(`ENEMY` / `COINGH`)
- 攻撃エフェクトは8属性ぶんを使い回し(`MON[...].fx`)
- 戦闘中に不正解だと残り時間が3秒へります(でたらめに押してクリアできないように)
- **ふくしゅう**: 一度でも間違えた問題、答えるのに10秒以上(数えタップは15秒)かかった問題が、子どもごとに30問まで たまります。ホームの「ドリル」から選んで やりなおし、2回続けて「一回で・はやく」正解すると消えます。問題は「種類+数字(`spec`)」で保存し、画像は保存しません(`BQ` で作りなおす)。おうちのひとの設定画面で一覧も見られます
- 問題: 数える(ゆびでさわって数える)・数字と絵のマッチ・サイコロの目・どっちが多い・足し算引き算・分解合成(10の補数)・くり上がり(10のまとまりの図つき)など。
  やさしい問題から始め、連続で正解すると少しずつ難しく、続けて間違えると少し戻ります。間違えた問題は答えを見せて読み上げ、少し間をあけてもう一度出します(`Pacer`)
- 設定画面に記録のバックアップ(ファイルに保存 / ファイルから戻す)
- 問題は読み上げ(Web Speech API)。助詞「は」は「わ」で読ませています
- Safari対策: 画面を離れて戻ったとき、BGM/効果音を復帰(`wake()` と `visibilitychange`)

## iPad で全画面で遊ぶ(おすすめ)
1. GitHub Pages を有効にする(Settings → Pages → Deploy from a branch → `main` / `/ (root)`)。
2. iPad の Safari で公開URLを開く → 共有ボタン →「ホーム画面に追加」。以降はアプリのように全画面で起動します。
3. 音を入れる: `python3 tools/make_sound_pack.py` で作った `chibi-sounds.json` をiPadに送り、
   ゲームの設定(スピーカーのボタン)→「おんげんを よみこむ」で1回だけ読み込みます。端末内に保存され、リポジトリには残りません。

## 開発
```
python3 tools/build.py   # src/ と assets/ から index.html を生成
```
- `src/game.src.html` ゲーム本体(HTML/CSS/JS)
- `src/atlas.json` 画像シートの切り出し座標
- `assets/` 画像(WebP)・背景・効果音・BGM
- `assets/source/monsters2_sheet.png` 追加モンスター8体の元絵(市松背景用)。`python3 tools/add_monsters2.py` で背景を抜いて `assets/atlas/monsters2.webp` を作ります
- **モンスターの追加(60体ぶん)**: ChatGPTで作った「マゼンタ背景・横4×縦5(各行: 進化前A/進化後A/進化前B/進化後B)」のシートを `assets/source/mon_sheetN.webp` に置き、`tools/sheets.json` に id の並びを書いて `python3 tools/add_monsters.py`(背景ぬき・切り出し・`assets/atlas/monsN.webp` と `src/atlas.json` を更新。敵のシート(横4×縦5の単体20体)は `sheets.json` に `{"as":"enemies","tag":"enemies2","ids":[...]}` で書く。numpy / scipy / Pillow が必要)。名前・属性(`fx`)・レア度(`r`)・とくぎ(`sk`)・ちから(`base`)・進化倍率(`evo`)・ひとこと(`tip`)は `src/monsters_extra.json` に書き、`python3 tools/build.py` で取り込みます(足りない項目や絵があると build が止まります)。詳しくは `docs/CONTENT_GUIDE.md`

## 記録(セーブデータ)について
保存先は localStorage の `chibiCalcQuest.v2`(3人分)。**この名前と形は変えないでください**(変えると記録が読み込めなくなります)。
項目を足すときは `defState()` に初期値を足すだけで、古い記録でもそのまま動きます。

## 音源について
BGM・効果音は、購入した素材のため **このリポジトリには含めていません**(無音で動きます)。
音を入れるには `assets/se/*.mp3`(16個)と `assets/bgm/{home,training,boss}.mp3` を置いて `python3 tools/build.py` を実行します。
ファイル名は `tools/build.py` の `SE` リストを参照。
