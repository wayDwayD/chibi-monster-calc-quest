# コンテンツ追加 指示書(ChatGPTで画像 → Claudeで取り込み)

ちびモンスターけいさんクエストに、敵・仲間・背景・ガチャの中身を一気に増やすための手順書です。
**流れは「ChatGPTで画像と名前を作る → このフォーマットでClaudeに渡す → Claudeが取り込む(背景ぬき・切り出し・登録・テスト・公開)」**。コードはさわらなくて大丈夫です。

---

## 0. 先に読む: 何が「そのまま増やせる」か

| 増やしたいもの | そのまま増やせる? | 備考 |
|---|---|---|
| ザコ敵(育成中に出る敵) | ◎ いくらでも | 画像+名前+必要な攻撃回数(1〜3)。いまは25種類+コインおばけ3種(`src/game.src.html` の `ENEMY` / `COINGH`) |
| ステッカー(ガチャのきせかえ) | ◎ いくらでも | 画像1枚+名前。いまは16個 |
| ドリルの数える絵(りんご等) | ◎ いくらでも | 画像1枚+名前。いまは16個。問題の種類が増える |
| 武器・防具 | ✕ 廃止 | 育成中の武器えらびをやめたため、ガチャにも出ません(もっていた子のずかんにだけ残る) |
| おまもり | △ | 絵と名前は簡単。**新しい効果**はClaudeがコードを書く |
| なかまモンスター | ◎ | **いまは156体**(属性ごと19〜21体、全属性に★4あり)。ステージ選択・ずかんはページ送り対応済み(ずかん42体/ページ)。`src/monsters_extra.json` に足すだけ(3-B参照)。目安は全体で160体まで(それ以上は読み込みの重さの改修が先) |
| ボス | △ | 13体×(通常/うら)=26レベル。各レベルが3ステージ(ミニボス→さいせん→レベルボス)。ミニボスは26体(`SB`配列)。さらに増やすなら `SB` と絵を足す改修が必要 |
| 背景 | △ | いまは6枚固定(ホーム/育成/ボス/うらボス/ガチャ/ずかん)。**ステージごとに変える仕組みはまだない**。依頼すれば作ります |

→ おすすめの順番: ①なかま・ザコ敵・ステッカー・ドリル絵(すぐ増える) → ②背景の切り替え+背景追加 → ③ボス・ステージ増

> 一度に増やしすぎると、ガチャの「すでに持ってるもの」が出やすくなったり、ずかんが長くなります。
> 目安: **1回の依頼につき、敵+ステッカー+道具で合計30点くらいまで**。なかまは1回に4〜8体。

## 1. 全部に共通する画像のルール

### 1-1. 絵柄(いまの絵に合わせる)
いまの素材は「太い濃紺の輪郭線 / ツヤのあるセル塗り / 大きくて丸い目 / ずんぐりしたちび体型 / ほぼ正面向き / 宝石や星のモチーフが1か所」です。
**一番ラクで確実なのは、ChatGPTに既存の絵を見せること**: 最初の会話で `assets/source/monsters2_sheet.png`(前回ChatGPTで作ったシート)か、遊んでいるゲームのスクショを添付して「この絵柄とまったく同じタッチで」と伝えてください。同じチャットの中で続けて作ると絵柄がぶれにくいです。

### 1-2. 背景は「透過」ではなく「単色ベタ塗り」にする(重要)
ChatGPTは透過PNGが苦手で、前回は市松模様が絵に焼き込まれてしまいました。なので**背景は一色のマゼンタ(#FF00FF)**にしてもらい、Claudeがその色を抜きます。
- キャラにピンク・紫・赤系が多いときは、背景を**ライムグリーン(#00FF00)**にする(キャラと同じ系統の色は抜けてしまうため)
- 白いキャラ(雲・雪など)は問題なし(白は抜かない)
- 影・地面・グラデーション・光のにじみ・文字・枠・ロゴは**入れない**
- キャラ同士・キャラと画像の端は**くっつけない**(まわりに余白)

### 1-3. 画像サイズ
ChatGPTの標準サイズでOK。ゲーム内では最大256px程度まで縮めるので、細かい絵は不要です。
- キャラ・アイテム: 横長 1536×1024 か 正方形 1024×1024
- 背景: 横長 1536×1024(Claudeが16:9=1280×720に切り出します)

### 1-4. 1枚に何体入れるか
- **なかま**: **1枚に10種類=20体**(横4×縦5。各行は左から 進化前A / 進化後A / 進化前B / 進化後B)。この方式で60体を作って、絵柄のぶれも少なく済みました(1254×1254で、1体あたり約250px。ゲーム内は256px以下なので十分)。正方形1:1で頼む
- **敵・ステッカー・アイテム**: 1枚に最大6個(横3×縦2)。個数が多いほど絵柄がぶれるので、6個が限度
- 並び順は「左→右、上→下」で、**表に書いた順番と同じ**にする(Claudeはこの順で名前を割り当てます)

### 1-5. 禁止事項
- 既存のキャラ・ポケモンなど、有名キャラに似せない(「〇〇風」と書かない)
- 怖すぎる・グロい・武器が血まみれなどはNG(4歳・6歳向け)
- 絵の中に文字を入れない(名前はゲーム側で表示します)

## 2. 共通スタイル文(毎回プロンプトの先頭に貼る)

```
子ども向けスマホゲーム用の、かわいいちびキャラのイラスト。
太めの濃い紺色の輪郭線、ツヤのあるセル塗り(ハイライトあり)、大きくて丸い目、
ずんぐりしたデフォルメ体型、ほぼ正面向き。宝石か星のモチーフを1か所入れる。
怖くしない・グロくしない。有名キャラに似せない。
文字・ロゴ・透かし・枠・影・地面は入れない。
背景は一色のベタ塗りマゼンタ(#FF00FF)だけにする。
グラデーション・模様・市松模様・影・光のにじみは背景に一切入れない。
キャラの中にマゼンタに近い色は使わない。
各キャラの周りに十分な余白をとり、キャラ同士や画像の端にくっつけない。
```
(ピンク系のキャラのときは「マゼンタ(#FF00FF)」を「ライムグリーン(#00FF00)」に変える)

## 3. 種類別: ChatGPTへの頼み方 と Claudeに渡す表

### 3-A. ザコ敵 (育成90秒のあいだに出てくる敵)
**サイズ感**: 画面で約290×270px。やさしい顔・小さめ。いま: スライム/どんぐり/ことりのたまご/ミニキノコ/ひよこコウモリ/ミニゴースト/こいしのかたまり/ちびカニ

**ChatGPT 手順**
1. まず企画: 「4〜6歳向けの計算ゲームの“ザコ敵”を12体考えて。名前(ひらがな/カタカナ・8文字以内)・見た目の特徴を表にして。いまの敵: (上の8体)とかぶらないこと。かわいくて、やっつけても怖くないこと」
2. 6体ずつ画像化: 「(共通スタイル文) 横3×縦2に並べて6体、敵キャラ。左上から順に: 1.〇〇 2.〇〇 … (特徴も書く)。全員こちらに向かってにっこり or ぷんぷん顔。」

**1枚に20体**(横4×縦5・マゼンタ背景・単体の姿)で頼むと速いです(2026-11に17体+コインおばけ3体をこの方式で追加)。取り込みは `tools/sheets.json` に `"enemy_sheetN.webp": {"as":"enemies","tag":"enemiesN","ids":[...20個...]}` を足して `python3 tools/add_monsters.py` → `ENEMY` に `['id','なまえ',必要な回数]` を足して `python3 tools/build.py`。
**コインおばけ**(レア敵): `COINGH` に `[id,なまえ,必要な回数,もらえるコイン,出る確率]`。確率の合計は10%以下に(ドリルの意味が薄れるため)。

**Claudeに渡す表**
| 順番 | 名前(ゲーム内表示) | 画像ファイル名 |
|---|---|---|
| 1 | ぷるぷるゼリー | enemy_sheet1.png の左上 |

### 3-B. なかまモンスター (進化前+進化後 / 10種類で1枚)
**サイズ感**: 進化前・後とも256px程度に縮小。輪郭がはっきりしている方が見やすい。
**ゲームのしくみ(2026-11〜)**: 強さは「ちから(`base`)」「進化倍率(`evo`)」のほかに、**レア度(★1〜4)・属性(8種)・とくぎ**で決まります。弱い子も、とくぎ(時間をのばす・まちがいを守る・ヒントを出す・ひっさつ・コイン・コンボ)と、ボスのじゃくてん属性との相性で活躍できます。**新しい子は「強い順」ではなく、レア度ごとに自由に足せます**(ガチャはレア度の重みで選ぶ)。
- ちからの目安: ★1 = 8〜20 / ★2 = 22〜32 / ★3 = 34〜40 / ★4 = 42〜48。進化倍率 1.35〜1.9
- ★1 のなかまは「よわいけど とくぎが便利」な子にしてあげると、ずっと使い道があります(例: スライムは ちから8・ひらめき)
- ★3 は5体以上、★4 は10体以上 集めてから出ます(`RAR_GATE`)。★4 はこの先も数体にとどめる(いまは5体)

**ChatGPT 手順 (10種類=1枚)**
1. 企画: 10種類ぶんの 名前(進化前: カタカナ6文字以内 / 進化後: 9文字以内)・モチーフ・属性・レア度・とくぎ・一言(ひらがな中心、20文字以内)を決める。テーマを1枚ごとにそろえると絵柄がぶれにくい(例: むし/うみ/おやつ/どうぶつ/ファンタジー)
2. 画像化(同じチャットで続けて作る)。1枚目のプロンプト例:
```
画像を1枚生成してください(正方形1:1、高解像度)。子ども向けモンスター育成ゲームのキャラクター素材シートです。
背景は完全にフラットな単色のマゼンタ(#FF00FF)で、市松模様・グラデーション・影・床・枠線・文字・ラベル・番号は一切入れないでください。
キャラクターは光沢のあるアニメ調のかわいいちびモンスターで、太めの濃い輪郭線、大きくてキラキラした目、鮮やかな配色、ゲームのスプライト風。
キャラクター自身にはマゼンタ・ピンク系の色は使わないでください。キャラ同士は重ならず、十分な余白をあけてください。
レイアウトは横4列×縦5行のグリッド。各行は左から[進化前A, 進化後A, 進化前B, 進化後B]の順です。
進化前は小さくて丸くかわいい姿、進化後は同じキャラの大きくてかっこよく豪華に進化した姿(同じ配色・モチーフを引き継ぐ)にしてください。
1行目A: ○○(特徴) → 進化後は…。1行目B: …(以下、5行目Bまで)
```
2枚目以降は「同じ形式・同じ画風・同じマゼンタ背景で、2枚目を生成してください(…)。今回のテーマは「○○」…」と続ける。

**取り込み(Claudeがやる / 自分でやるなら)**
1. 画像を `assets/source/mon_sheetN.webp`(PNGでもよい。WebP品質96で十分)に置く
2. `tools/sheets.json` に `"mon_sheetN.webp": {"as":"monsters","tag":"monsN","pairs":true,"q":80,"spr":240,"ids":["id1",…10個…]}` を足す(id は英小文字。並びは 行→(A,B) の順。古い形式の配列でも可)
3. `src/monsters_extra.json` に各 id の `n1 n2 fx r sk base evo tip` を足す
4. `python3 tools/add_monsters.py --debug`(切り出し確認用の画像が `/tmp/monsN_debug.png` に出る。塊の数が合わないときは警告が出る)→ `python3 tools/build.py`
- うまく切れない例: キャラ同士がくっついた(縦につながったら自動で切る)/ 小さな飾りが別のキャラに付いた(`tools/add_monsters.py` の `DROP` に座標を書いて捨てる)

いまの156体は、`src/monsters_extra.json` と、はじめの16体(メラリ…ミニメカドラ)です。

### 3-C. ボス (通常 と うら のペア)
**サイズ感**: 画面で約380×318px。ザコより大きくて迫力がある、でも怖すぎない。**うらボス=同じボスの色違い・凶悪版(目つきが鋭い、トゲが増える、暗い配色)**。
**ChatGPT**: 「(共通スタイル文) 横長1536×1024に、左に通常版・右にうら版(同じボスの色違いで、目つきが鋭く、トゲや装飾が増えた凶悪版)。テーマ: 〇〇。通常版は大きくて強そうだけど、子どもが怖がらないユーモラスな顔」

| ステージ番号 | ボス名(うら版は「(うら)」が自動で付く) | 画像 |
|---|---|---|
| 14番目〜(新規) | ○○ | boss14.png |

**ミニボス(26体)**: `tools/sheets.json` の `boss_sheet1.webp`(4×5=20体)/`boss_sheet2.webp`(3×2=6体) は `{"as":"bosses","tag":"bosses2","spr":300,"cols":3,"ids":["sb01_jelly",...]}` の形(単体シート。`spr`=スプライト長辺px、`cols`=列数)。id は `sbNN_slug`(`SBK(i)`)で、名前とじゃくてん属性は `src/game.src.html` の `SB=[slug,名前,属性]` に書く。
**セーブの追加項目**(既存キーは変えず、足すだけ): `S.round`, `S.rounds{レベル:クリア済みステージ数}`, `S.star{"L-r":★数}`, `S.zs{ミニボス図鑑}`。

※ボスを増やす場合は「何ステージまで増やすか」「うらは続けて別の周にするか」を一緒に相談してください(HPの計算式、ステージ選択画面の改修が必要)。

### 3-D. 背景
**場所ごとのルール(画面の1280×720で、ここに重なるものがあります)**
- 上端 約90px: タイマーやステータス → 暗めかシンプルに
- 画面中央の上〜中段(約y120〜320): クイズのカードが重なる → ごちゃごちゃさせない
- 左 x100〜390 / 右 x770〜1150、y300〜610: 仲間と敵が立つ → 地面か床にして、その場所に細かい絵を置かない
- 下端 約100px: 答えのボタン → シンプルに
- 構図の中心は画面中央に(Claudeが16:9で上下を少し切るため、上下ギリギリに大事なものを置かない)
- 文字・看板・キャラは入れない

**ChatGPT**: 「子ども向けスマホゲームの背景イラスト。横長1536×1024。場所: 〇〇。やさしいパステル調の昼のシーン、手前は広くて平らな地面で何も置かない、奥に遠景、中央上部は空や壁などシンプル。文字・キャラクター・看板は入れない。(ボス戦用なら)少し暗く、迫力のある空」
(背景は背景色ぬきをしないので、共通スタイル文の「マゼンタ」は不要)

| 種類 | 場所/テーマ | ひもづけ先 | 画像 |
|---|---|---|---|
| 育成 / ボス / うらボス / ホーム / ガチャ | 草原 | ステージ1〜3 | bg_01.png |

※いまの仕組みは「育成=1枚、ボス=1枚、うらボス=1枚」固定です。ステージごとに変えるには切り替えの改修が必要なので、背景を作る前に「**ステージ何番〜何番はこの背景**」の対応を決めておくと速いです(例: 1〜3 草原、4〜6 洞窟 …)。

### 3-E. ガチャの中身 (おまもり・ステッカー)
**武器・防具は廃止**しました(育成中の選択をなくしたため)。ガチャは**毎回なかまが出ます**。おまもり・ステッカーは「おまけ」(25%)で出ます。
**おまもり**: 特別な効果(ハート=ちから+3、時計=ボス時間+など) / **ステッカー**: 見た目だけ(コレクション)

**ChatGPT**: 「(共通スタイル文) 横3×縦2に6個。単体のアイテムアイコン、斜め45度か正面。1.〇〇 2.… 」

| 種類 | 名前 | 数値/効果 | 画像 |
|---|---|---|---|
| おまもり | ○○のおまもり | (新しい効果。例: ガチャ1回ぶんのコインが戻る) | … |
| ステッカー | ペンギン船長 | (なし) | … |

- おまもりの新効果はコードに追加するので、**効果を日本語の文章**で書いてください(例: 「まちがえても残り時間が減らない(1回だけ)」)。実現できるか・バランスはClaudeが判断して相談します。
- ステッカーはキャラ・乗り物・食べ物・飾りわくなど何でもOK。

### 3-F. 攻撃エフェクト (新しい属性を作るとき)
いまは8属性ぶん(進化前/進化後の2枚ずつ)。**属性を新しく作るときだけ**必要です。
**ChatGPT**: 「(共通スタイル文) 横2に、左: 弱めの〇〇属性の攻撃エフェクト、右: 派手な〇〇属性の攻撃エフェクト。キャラは入れない、エフェクトだけ」
→ 新しい属性は、なかまのガチャ以外にゲーム全体(属性の名前など)の登録が必要なので、まとめてClaudeに相談してください。

## 4. Claudeに渡すとき

1. 画像ファイル(PNG)を全部添付するか、リポジトリの `assets/incoming/` に置く(ファイル名は何でもOK。表と対応が分かればよい)
2. 上の「渡す表」をそのまま貼る
3. こう伝える: 「`docs/CONTENT_GUIDE.md` の手順で、添付の〇〇を取り込んで。背景はマゼンタ(or ライムグリーン)の単色ベタ」

**Claudeがやること**: 背景色ぬき → 1体ずつ切り出し → 縮小して画像シートに詰める(`assets/atlas/`)→ ゲームに登録(名前・数値・ガチャ・ずかん)→ ブラウザで動作とセーブ互換テスト → 公開(GitHub)。

**背景ぬきの道具**: なかまモンスターのシート(マゼンタ単色背景)は `tools/add_monsters.py` で取り込めます(3-B)。ザコ敵・ステッカーなど他の種類は、同じ考え方で取り込み用の道具を足します。

## 5. 絶対に守ること

- **セーブデータ**: 既存の名前・順番・IDは変更しない(子どもの記録が読めなくなる)。追加するだけ。この指示書のとおりに渡せば、Claudeが壊さずに足します。
- **音は入らない**: 効果音・BGMは購入素材のため、リポジトリには含まれません。新しい音を足したいときは別途相談。
- **容量**(画像は `tools/encode_webp.js`(node+sharp。`cd tools && npm install`)で書き出すと同じ見た目で約15%軽い。なければ自動でPILに切り替わる。元絵が残っていない古いアトラスは `python3 tools/recompress_old.py` で1回だけ軽くした): 画像が増えると読み込みが重くなります(いま約10.8MB・圧縮されて通信は約8MB・なかま156体。シートは `q:80`・`spr:240` で軽くしてある)。目安は全体で10〜12MB以下。画像は使うときに切り出す方式にしてあるので起動は軽いですが、ダウンロード量は増えます。キャラは256pxまで縮めるので、細かい絵・高解像度は不要。
- **iPadでの確認**: 取り込み後は必ず実機で、ホームの「ずかん」「ガチャ」「バトル」を見て、表示のズレ・名前の長さ切れがないか教えてください。
